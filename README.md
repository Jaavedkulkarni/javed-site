# जावेद कुलकर्णी – लेखक वेबसाइट (Next.js + Postgres, Vercel वर चालणारी)

यात आहे: मुख्य पान, पुस्तकांची पाने, लेखन (ब्लॉग), लेखक, संपर्क, वाचक नोंदणी/लॉगिन, "पासवर्ड विसरलात?", वाचक पॅनेल (आवडती पुस्तके, अभिप्राय) आणि ॲडमिन पॅनेल.

## तुम्हाला लागणारी खाती (सर्वांना सुरुवातीला मोफत योजना असते)
1. **GitHub** (कोड ठेवण्यासाठी)
2. **Vercel** (वेबसाइट चालवण्यासाठी) – तुमचे आधीच आहे
3. **Postgres डेटाबेस** – Vercel मधूनच जोडता येतो (Neon)
4. **Vercel Blob** – कव्हर फोटो आणि तुमचा फोटो ठेवण्यासाठी (Vercel मधूनच)
5. **Resend** – ईमेल पाठवण्यासाठी (नवीन संदेशाची सूचना, पासवर्ड रीसेट)

## टप्पा १ – GitHub वर चढवा
1. github.com वर **New repository** बनवा (नाव उदा. `javed-site`, Private ठेवा).
2. zip उघडून आतल्या **सर्व फाइल्स आणि फोल्डर** repository मध्ये **Add file → Upload files** ने ड्रॅग करा आणि **Commit** करा.
   (`node_modules` किंवा `.next` फोल्डर नसतात, ते बरोबर आहे.)

## टप्पा २ – Vercel ला जोडा
1. Vercel मध्ये **Add New → Project** → तुमची GitHub repository निवडा → **Deploy**.
2. पहिल्या डिप्लॉयनंतर साइट उघडल्यावर "डेटाबेसला जोडता आले नाही" दिसेल. ते अपेक्षित आहे, पुढचे टप्पे करा.

## टप्पा ३ – डेटाबेस आणि फोटो स्टोरेज
Vercel प्रोजेक्टमध्ये **Storage** टॅब उघडा:
1. **Postgres (Neon)** बनवा/जोडा. शक्य असल्यास भारताजवळचा region (Mumbai/Singapore) निवडा. यामुळे `DATABASE_URL` (किंवा `POSTGRES_URL`) आपोआप जोडले जाते.
2. **Blob** store बनवा (**Public** access). यामुळे `BLOB_READ_WRITE_TOKEN` आपोआप जोडले जाते.

## टप्पा ४ – Environment Variables
Vercel → प्रोजेक्ट → **Settings → Environment Variables** मध्ये हे जोडा:

| नाव | काय भरायचे |
|---|---|
| `SETUP_KEY` | तुमचा स्वतःचा, लांब गुप्त शब्द (फक्त पहिल्या सेटअपसाठी) |
| `SITE_URL` | `https://javedkulkarni.com` |
| `RESEND_API_KEY` | Resend मधून मिळालेली key |
| `MAIL_FROM` | `noreply@javedkulkarni.com` (Resend मध्ये डोमेन verify केल्यावर) |

नंतर **Deployments → ... → Redeploy** करा (नवीन variables लागू होण्यासाठी).

## टप्पा ५ – डोमेन
Vercel → **Settings → Domains** → `javedkulkarni.com` (आणि `www.javedkulkarni.com`) जोडा. Vercel जे DNS रेकॉर्ड सांगेल ते तुमच्या डोमेन कंपनीकडे भरा. तुम्ही हे आधीच केले असेल तर इथे "Valid" दिसले पाहिजे.

## टप्पा ६ – पहिला सेटअप
1. `https://javedkulkarni.com/setup` उघडा.
2. SETUP_KEY, तुमचे नाव, ईमेल आणि पासवर्ड भरा. यातून टेबल्स, २० पुस्तके आणि ॲडमिन खाते तयार होते.
3. आता ॲडमिन पॅनेल उघडेल. **सेटिंग्ज** मध्ये तुमचा फोटो, सोशल लिंक्स; **पुस्तके** मध्ये कव्हर फोटो आणि खरेदी लिंक भरा.
4. सेटअप झाल्यावर `/setup` आपोआप बंद होते (ॲडमिन आधीच असल्याने).

## ईमेल (Resend)
1. resend.com वर खाते करा → **Domains** मध्ये `javedkulkarni.com` जोडा → ते जे DNS रेकॉर्ड सांगतील ते डोमेनमध्ये भरा → Verified झाल्यावर **API Keys** मधून key बनवा.
2. ती key Vercel मध्ये `RESEND_API_KEY` म्हणून भरा.
3. डोमेन verify होण्यापूर्वी Resend फक्त तुमच्या स्वतःच्या Resend-ईमेलवर पाठवू देते. त्यामुळे "पासवर्ड रीसेट" वाचकांसाठी डोमेन verify झाल्यावरच चालेल.

## आपल्या संगणकावर चालवायचे असेल तर (ऐच्छिक)
`.env.example` कॉपी करून `.env.local` बनवा, भरा, मग `npm install` आणि `npm run dev`.

## महत्त्वाचे
- डेटाबेसचा बॅकअप: Neon मध्ये स्वयंचलित बॅकअप/restore सुविधा असतात, त्या तपासा.
- `SETUP_KEY` कोणाला सांगू नका.
- हा कोड बदलला आणि GitHub वर टाकला की Vercel आपोआप नवीन आवृत्ती चालवते.
